# Panel de Contenido · Vídeos

Crea un vídeo vertical (1080×1920, formato B) para cada publicación de Airtable que aún no lo tiene y lo sube al campo «Vídeo».

- Voz: Piper, voz es_ES «davefx» (gratuita; datos CC0, modelo MIT). Voz de narrador genérica, no imita a nadie.
- Música: creada con código (`videos/musica.py`), sin licencias de terceros.
- Gancho, cita, autor y fuente: solo del banco verificado de Airtable. Nada inventado.
- Foto: «Foto manual» o la foto libre de Wikipedia; crédito del campo «Crédito foto».

Se ejecuta a mano desde **Actions › Vídeos de las citas › Run workflow**. Necesita el secret `AIRTABLE_TOKEN`.
